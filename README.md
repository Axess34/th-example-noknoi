# Nok Noi Coffee & Bakery (Thai Local example site)

A fictional example website (café, Chiang Mai) made by Thai Local (https://thailocal.online/) to show what a local business website can look like. The business, prices, reviews and contact details are placeholders. The site is noindex and robots.txt blocks crawlers.

Live: https://noknoi.thailocal.online/
